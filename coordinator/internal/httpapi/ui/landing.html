QUICK START

3분이면 충분합니다

Agent를 설치하고, Coordinator에 연결하고, 작업을 시작하세요.

1

Agent 설치

npm으로 전역 설치합니다. Claude Code가 설치된 모든 머신에서 실행 가능합니다.

$ npm i -g @clwclw-monitor/agent
2

Coordinator에 연결

Agent를 실행하면 자동으로 Coordinator에 등록됩니다. 대시보드에서 바로 확인하세요.

$ clw-agent work --url https://your-coordinator.com --channel backend
3

작업 분배 시작

대시보드에서 채널과 작업을 생성하면 Agent가 자동으로 claim하고 실행합니다.

SECURITY

보안을 최우선으로

로컬 환경의 민감한 정보를 다루기에, 보안은 타협 없이.

JWT Authentication

사용자 인증은 JWT 토큰 기반. 24시간 만료, 서버 상태 없이 안전한 세션 관리.

Password Policy

대문자, 특수문자 필수 포함. 최소 6자 이상. bcrypt 해싱으로 안전하게 저장.

API Token Guard

Agent 통신은 Bearer 토큰으로 보호. 무단 접근을 원천 차단합니다.
