Agent Setup Guide

Claude Code 세션을 Coordinator에 연결하는 방법을 안내합니다.

1

Install

npm으로 Agent를 전역 설치합니다. Node.js 14 이상이 필요합니다.

$ npm i -g @clwclw-monitor/agent
설치 후 clw-agent --help로 사용 가능한 명령어를 확인하세요.
2

Connect

Agent를 실행하면 브라우저 인증 창이 열리고, 로그인 후 자동으로 Coordinator에 등록됩니다.

$ clw-agent work --url https://your-coordinator.com --channel backend
--url Coordinator 서버 주소
--channel 구독할 채널 이름 (쉼표로 복수 지정 가능)
--name Agent 표시 이름 (기본: hostname)
--tmux-target tmux 세션:창.패인 (예: claude:0.0)
3

Work

Agent가 연결되면 Dashboard의 Agents 패널에 표시됩니다. 이제 Task Board에서 작업을 생성하면 Agent가 자동으로 claim하고 실행합니다.

Heartbeat로 실시간 상태 모니터링
FIFO 기반 자동 작업 분배
tmux를 통한 원격 명령 주입
Chain 기반 순차 실행
