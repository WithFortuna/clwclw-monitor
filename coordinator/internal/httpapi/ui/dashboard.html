Agent Setup Guide

Claude Code 세션을 Coordinator에 연결하는 방법을 안내합니다.

1

Install

npm으로 Agent를 전역 설치합니다. Node.js 14 이상이 필요합니다.

$ npm i -g @clwclw-monitor/agent
설치 후 clw-agent --help로 사용 가능한 명령어를 확인하세요.
2

Setup

알림 채널(Telegram, Email, LINE)과 Claude Code 훅을 대화형 위저드로 설정합니다.

$ clw-agent setup
알림이 필요 없다면 이 단계를 건너뛸 수 있습니다.
3

Login

Coordinator에 인증하고 Agent를 등록합니다. 대시보드에서 바로 확인하세요.

$ clw-agent login
Heartbeat로 실시간 상태 모니터링
FIFO 기반 자동 작업 분배
tmux를 통한 원격 명령 주입
Chain 기반 순차 실행

API Usage

          

          

            curl -X POST https://your-host/v1/external/tasks \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "backend-alerts",
    "chain":   "Error Monitoring",
    "title":   "NPE in UserService",
    "description": "stack trace..."
  }'
          

          

            Fields:
            channel (required) — channel name ·
            chain (optional) — reuse or create chain by name ·
            title (required) ·
            description, priority, execution_mode (optional)
